## キュー参加条件

| 対象 | キューへの参加方法 | キュー参加時の申告内容 |
|---|---|---|
| キラープレイヤー | 1人でキューに参加 | 使用するキラー1体 |
| サバイバープレイヤー | ソロまたはパーティでキューに参加 | なし |

空いているサバイバー枠は、ソロまたはパーティでキューに参加しているプレイヤーで埋められる。

## リザルト情報

| 項目 | 説明 |
|---|---|
| 勝利陣営 | キラーまたはサバイバーのどちらが勝利したか。引き分けの場合は記録しない |
| 引き分け | 試合が引き分けだったことを示す。勝利陣営とは両立しない |
| 残り発電機数 | 試合終了時に修理されていなかった発電機の数（0〜5） |
| フックステージ | 試合中にキラーが行ったフックステージの合計数（0〜12） |
| キル数 | 死亡したサバイバーの数（0〜4） |

## レーティング

1v4 PUG Casualでは、ゲームモードごと、かつキラーごとに分かれたレーティングを使用する。

このレーティングの範囲は、次の両方のフェーズで同じである:

- **マッチメイキングフェーズ:** 該当するキラーの1v4 PUG Casual用レーティングを使ってマッチを組む。
- **レーティング更新フェーズ:** 試合後に、同じ範囲のレーティングを更新する。
