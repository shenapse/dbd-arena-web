## Overview

A ranked 1v1 mode that tests both your killer and survivor chase skills.
In each round, you take turns playing both roles against your opponent.
The player who survives longer wins the round; the first to win two
rounds wins the best-of-three match.

Queue solo with killer(s) from the available pool. Each killer has a fixed
map and specific build restrictions, with a separate rating for that killer.

## Game Structure

| Attribute | Value |
|---|---|
| Team structure | 1 × Player A vs 1 × Player B |
| Map selection | Fixed per killer character |
| Build restriction | Yes — see per-killer balancing |
| Pre-match killer reveal | Yes — the killer character is known to both sides before the match starts. |
| Pre-match player reveal | Yes |
| Number of rounds | 3 (Bo3) |
